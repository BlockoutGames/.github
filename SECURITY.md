# Security policy

Thank you for helping keep Blockout Games and its players safe.

This policy covers every Blockout Games repository and every game we publish on Roblox. A
repository with its own `SECURITY.md` follows that file instead.

## Report privately

**Never post an exploit in public**: not in a GitHub issue, a game's chat, a review, a video or a
Discord. Other players can copy it before we can fix it.

Report it here, privately:

**[Report a vulnerability](https://github.com/BlockoutGames/.github/security/advisories/new)**

Only the studio's founders can read the report. If you do not have a GitHub account, email
**hello@blockoutgames.com** with `Security` in the subject.

## What to include

- **Where.** The game and place (a link is best), our website, or the repository and file.
- **What.** What an attacker can do, and what they need first (an account, a game pass, a rank).
- **How.** Steps we can follow to see it happen. A short private video helps.
- **When.** When you found it, and whether you have seen anyone else using it.

## What counts

| In scope                                                                              | Not ours to fix                                                                                         |
| ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Duplicating items or currency, getting paid items or Robux products for free          | Bugs in Roblox itself, its client or its website: report them to [Roblox's bug bounty](https://hackerone.com/roblox) |
| A client making the server change something it should decide (damage, price, position) | Exploit tools that only change what the cheater sees on their own screen                               |
| Reading or changing another player's data or saves                                     | Gameplay balance ("this gun is too strong"): that is [support](https://github.com/BlockoutGames/.github/blob/main/SUPPORT.md)                              |
| Getting staff or admin powers without the rank for them                                | Accounts lost to phishing or shared passwords: contact [Roblox Support](https://www.roblox.com/support) |
| Leaked secrets, keys or tokens in any of our repositories                              | Reports from automated scanners with no working example                                                 |
| Problems with www.blockoutgames.com or our sign-in                                     |                                                                                                         |

## What happens next

1. We confirm we have your report within **3 days**.
2. We tell you whether we can reproduce it, and roughly when a fix will ship.
3. We fix it, publish the fix to the live game, and tell you.
4. If you want, we thank you by name (or by Roblox username) in the release notes.

Please give us a reasonable time to fix a problem before telling anyone else about it.

## Good faith

If you act in good faith, follow this policy and stop as soon as you have shown the problem, we
will not ban your account or take action against you for finding it. Please do not:

- use an exploit beyond what it takes to show it works,
- affect other players, their items, their data or their game,
- keep, share or sell anything you got through it.

Thank you for telling us first.
